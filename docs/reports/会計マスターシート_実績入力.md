## 月を締めるときにやること（元のファイル）

1. 日次売上シートにその月の数字を入れる
2. freee実績に、その月の科目ごとの合計行を足す（B列は 2026-11 の形）
3. その月のシートの C24・C28 を上の式に置き換える（年月を変える）
4. 月末の口座残高が実際と合うように C6 に調整額を入れ、メモを書く

## 操作の教訓（追加）

- シートの読み取りと確かめは、Drive コネクタで xlsx に書き出して openpyxl で読むのが速い（数式も計算結果も全部読める）。入れる前と後を書き出して比べると、変わったセルが全部分かる
- 入力は、ページの中で `navigator.clipboard.writeText` → シートで cmd+v が速くて確実。タブ区切り・改行区切りで表のまま貼れる。日本語も数式も通る。貼る前に名前ボックスで先頭のセルへ飛び、貼る範囲に結合セルと既存の式が無いことを確かめる
- freee実績の B列は書式が「書式なしテキスト」。`2026-08` をそのまま貼る。先頭に `'` を付けると `'` ごと文字として入り、SUMIFS に拾われない。書式が標準のセルでは逆に、`2026-08` が日付（2026/08/01）に変わる
- Google スプレッドシートでは `SUMPRODUCT(SUMIFS(…,{配列}))` も `SUM(ARRAYFORMULA(SUMIFS(…,{配列})))` も 0 を返す。複数の科目を足すときは `SUMPRODUCT((条件)*ISNUMBER(MATCH(列,{配列},0))*金額列)` を使う
- 試し打ちは空いたセルで行い、cmd+z で戻して、空に戻ったことを確かめる
