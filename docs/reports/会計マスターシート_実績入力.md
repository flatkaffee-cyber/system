## 作業の事故と復旧

メモを打ち直すとき、名前ボックスで E11:E28 を選んで Delete した。18行目の見出しが B〜E の結合セルなので選択が B11:E28 に広がり、8〜10月の3枚で科目名・金額・合計の数式まで消えた。すぐ「元に戻す」で3枚とも戻し、金額・科目名・数式が元どおりなのを確認した。メモは1セルずつ入れ直した。

教訓（Google スプレッドシートをブラウザで操作するとき）:
- **範囲を選んで Delete しない**。結合セルにかかると選択が広がる。消すのは1セルずつ
- 入力は1列ずつ、名前ボックスで先頭のセルへ飛び、値を改行でつなげて打つ（タブは効かない）
- 日本語は、編集状態にしてから打つ（Enter → 文字 → Enter）。選んだだけのセルに打つと、最初の半角文字より前が欠ける
- 空のセルを飛ばすのは Enter 2回（編集に入る→確定）
- gviz の CSV は空行を詰めるので行番号がずれる。行は画面で確かめる
