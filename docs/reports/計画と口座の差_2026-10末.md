# 当初の計画と実際の口座の差（2026年10月末）

2026-11-16 坂本さんの質問「当初の計画では口座に毎月100万くらい残るはずだった。なぜ残っていないのか。計画から漏れている支出があると思う」。

- 計画: 会計マスターシート（直す前の書き出し）の各月シートの「月末口座」。8月 1,214,112／9月 986,816／10月 1,689,073／11月 1,391,330／12月 1,093,587
- 実際: freee の試算表（2026-11-16 時点）。10月末の口座 38,922
- 差: **−1,650,151**（下の表で1円まで説明がつく）

## 計画の中身

シートの「月末口座」は、次のものだけで計算されていた。

- 入るお金: 資本金 3,000,000＋公庫の融資 4,500,000＋クラファン 1,000,000（10月）
- 出るお金: 開業までの一括経費 5,772,046（物件 845,000・内装 3,500,000・設備 1,263,046・釣銭と消耗品 50,000・設立 114,000）、6〜7月の経費 286,547、8月以降は人件費（役員報酬・社保・業務委託）だけ
- **8月以降の売上と、人件費以外の費用（仕入・家賃・光熱・消耗品など）は入っていない**（freee から取り込む作りで、まだ空だった）
- 売上計画シートの方の月末口座（8月 1,567,934 … 10月 1,985,738）は売上と原価30%・アルバイト代を入れているが、こちらも8月以降の家賃・光熱・通信・保険・消耗品は 0 円

## 出どころ

- 計画: マスターシートの直す前の書き出し（2026-11-15 22:35 の xlsx）。各月シートの C5・C6・C30・D54・I75、一括経費の 34〜53行目
- 実際: freee の試算表（貸借 8/1〜10/31、損益 6/9〜7/31 と 8/1〜10/31）。資産・負債・損益の全科目で、計画との差の合計が口座の差と一致することを確かめた
- 消耗品費の中身: /api/keiri/monthly の出金の行
