# サイト一覧（/sites）

2026-11-06 坂本さんの依頼で作った。契約や毎日使うサイトの管理画面へ、1か所から飛ぶためのタブ。サイドバーの「サイト」にある。

- データは契約（/contracts）と同じ。管理ページのURL・ログインIDがあるものが出る
- /contracts は期限を見る場所、/sites はすぐ開く場所
- パスワードは置かない。ログインID・お客様番号まで
- 契約の中身（開始日・金額・メモ）があるものは /sites からは消せない
