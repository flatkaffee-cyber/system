# 現金の管理（2026-11-04 案。坂本さんの返事待ち）

売上金と小口が混ざり、現金払いの記録が抜けたことで、帳簿と手元が約 ¥10万ずれた。同じことが起きないように、入れ物と入金の日を固定する。

## 入れ物は3つ

| 入れ物 | 金額 | 使い道 |
|---|---|---|
| レジ | 常に ¥30,000 | お釣りだけ。ここから買い物はしない |
| 売上袋 | 毎日増える | 入金するだけ。今の「11月売上の財布」をそのまま使う。月ごとに分けなくていい |
| 小口 | 常に ¥20,000 | 両替用の小銭、少額の現金の買い物、イベントの釣り銭 |

個人への貸し出しはどの入れ物からもしない。

## 毎日（レジ締めのとき）

- レジを ¥30,000 に戻し、残りを売上袋へ。1万円札と5千円札から先に抜いて、千円札と小銭をレジに残す
- 小銭が足りなければ、小口の小銭と売上袋の札を同じ額だけ入れ替える
- 10月の現金の注文155件は全部 ¥50 単位。10円玉と1円玉はほぼ要らない

レジの中身の目安（仮）: 五千円札1枚 ¥5,000、千円札15枚 ¥15,000、500円玉10枚 ¥5,000、100円玉40枚 ¥4,000、50円玉20枚 ¥1,000。

## 毎週月曜（入金の日）

1. 小口の残りとレシートを足して ¥20,000 になるか確かめる
2. レシートの分を売上袋から小口に足して、¥20,000 に戻す
3. コンビニ払いの請求書があれば、同じセブンで売上袋から払う。受領証は領収書に現金払いで登録する
4. 売上袋の札を全部入金する。硬貨は入らないので、小銭は両替用に残す

月曜にする理由: 売上の多い土日の現金がまとまる。火曜は定休日。A週はアミカに行く日でもある。

月曜を待たずに行くとき:
- 6日（報酬・返済）と27日（家賃の引き落とし）に口座が足りないとき
- 売上袋が ¥100,000 を超えたとき（イベントのあとなど）

## 毎月末

レジ＋売上袋＋小口を全部数えて、freee の現金と比べる。帳簿の現金は1つのままでいい（3つの合計＝freee の現金）。

## 数字の根拠

- 10月の店の現金売上 ¥205,500（155件）。週の平均 約¥46,000。週ごとは 10/5〜 ¥37,150、10/12〜 ¥69,200、10/19〜 ¥28,550
- イベントの現金は別に増える（ひこねいろ ¥48,400、滋大祭 ¥40,600、城祭り ¥16,300）
- 毎月の現金払いの請求書: ダイキン ¥31,350、USEN ¥6,750、水道 ¥4,092（計 ¥42,192）。小口には収まらないので入金の日に売上袋から払う
- ATM の手数料は1回 ¥110（10/29 の明細）。週1で月 ¥440〜550
- セブン銀行 ATM は札だけで、硬貨は使えない。1回に50枚まで（セブン銀行のよくある質問）。10/29 の ¥109,000 は2回に分けて ¥220 かかった
- これまでの入金は 8/31・9/10・9/22・10/29 で間隔がばらばら

## 切り替えの手順

1. レジ・小口・財布を全部数えて、freee の現金と比べる
2. レジ ¥30,000、小口 ¥20,000 にして、残りを全部売上袋へ
3. 札を入金する
