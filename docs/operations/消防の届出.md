# 消防の届出（2026-11-25 調べ）

「まだ届出が出ていないらしい」（坂本さん）。flat.（京町2丁目・北棟、8/8 開業、1階と2階を客席に使用）の場合の整理。
窓口：彦根市消防本部 予防課 0749-22-0332（平日9〜17時、12〜13時を除く）

| 届出 | flat. に要るか | 部数・添付 |
|---|---|---|
| 防火対象物使用（変更）開始届出書 | 要る。期限は過ぎている見込み（他市は使用開始の7日前まで。彦根の期限は未確認） | 正副各1部＋添付書類（届出書の備考7。図面など） |
| 消火器の設置・点検報告 | 要る（火を使う飲食店は面積に関係なく義務。安全装置などの免除あり）。設置後6か月ごとに点検、1年に1回報告 | 点検結果報告書 |
| 防火防災管理者選任届出書・消防計画作成届出書 | 収容人員30人以上なら要る（建物全体で数える）。flat. の人数は未計算 | 各 正副各1部、講習の修了証の写し・消防計画 |
| 火を使用する設備等の設置届出書（様式第4号） | 未確認。対象になる大きさ（kW）は予防課に聞く | 正副各1部＋備考8の書類 |
| 消防用設備等設置届出書 | 未確認（建物の広さ・設備しだい） | |

- 様式: https://www.city.hikone.lg.jp/shinseisho/8121.html
- 電子申請（e-Gov）もできるが、パソコンのみ・副本が返らない
- 消火器の資料: https://www.city.hikone.lg.jp/material/files/group/91/insyokuten-syokaki.pdf
