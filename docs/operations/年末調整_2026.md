# 2026年の年末調整と1月の提出（2026-11-12 作成）

坂本さんの質問「年末調整ってしなきゃいけないの？」への答えと、やることの一覧。

## 結論

- 役員3人（坂本・櫻井・町田）に毎月 ¥62,999 の役員報酬（給与）を払っているので、会社は年末調整をする。役員も給与をもらう人なので対象になる
- 毎月の源泉所得税を 0 円（月額表の甲欄で ¥88,000 未満）にしているのは、3人が「扶養控除等申告書」を会社に出している前提。出していない人がいれば今出してもらう
- 2026年の報酬は1人 ¥62,999 × 4か月（9〜12月）＝ ¥251,996。社会保険料を引くと所得はほぼ無く、**所得税は 0 円の見込み**。年末調整は「0円で合っている」と確かめて書類を作る作業になる（返すお金も、追加で取るお金も無い見込み）
- 國仲さんは業務委託（給与ではない）なので年末調整はしない

## 坂本さんの答え（2026-11-12）

- 扶養控除等申告書は **3人とも出していない**
- 2026年1〜8月にほかの会社の給与があるのは **坂本・町田**（櫻井は無し）
- アルバイトに給料は払っていない

### 申告書を出していなかったことの影響

- 申告書が無い人の毎月の源泉所得税は「乙欄」で計算する決まり。社会保険料を引いたあとの額が ¥88,000 未満なら、その 3.063%
- 9/6・10/6・11/6 の3回は 0 円（甲欄の計算）にしていた。乙欄なら1回 約 ¥1,600〜1,900、**1人 約 ¥5,500、3人で 約 ¥1.6万** を引いて、翌月10日までに納めるはずだった
- 年末調整は、その年の最後の給与（12/6）までに申告書を出した人にしかできない。**今すぐ3人に「2026年分 扶養控除等（異動）申告書」を書いてもらう（日付は書いた日。さかのぼった日付にはしない）**
- 年末調整では1年分の税金を計算し直す。櫻井は0円の見込み。坂本・町田は前の会社の給与と合わせて計算するので、前の会社の源泉徴収票（退職のときにもらうもの）が要る。前の会社で多めに引かれていれば返ってくることが多い
- 引いていなかった乙欄の分（約 ¥1.6万）を、12/6 に引いて納めてから年末調整で返すのか、別の扱いでよいのかは、**彦根税務署（無料の相談）か税理士に一度確かめる**。1か月分の不足が3人合わせて1万円未満なので、不納付加算税・延滞税はほぼかからない

## 國仲さん（業務委託）の扱い

- 会社がすること: 年末調整・源泉徴収票は無し。カフェの業務は、源泉徴収が要る「報酬」（原稿料・デザイン料・講演料など）に当たらないので、源泉も支払調書も要らない
- 毎月の請求書を國仲さんから出してもらって残す（経費の証拠）。1年分の支払いの一覧（9〜12月 ¥52,056 × 4 ＝ ¥208,224）を渡すと、國仲さんの確定申告が楽になる。立替の返済（毎月 ¥30,000）は売上ではないので一覧で分けて書く
- 國仲さん本人: 個人事業として 2027/3/15 までに確定申告。開業届は 9/1。青色申告の承認申請の期限は「業務を始めた日から2か月」で、初めて報酬を受け取った日（10/6）ではない。9/1 から2か月の 11/1 が日曜なので **11/2 が期限で、もう過ぎた**（11/12 坂本さんの質問に回答）。2026年分は白色申告になる。今から出せば 2027年分から青色（2027/3/15 までに出せばよい）。2026年の報酬は4か月で約 ¥21万なので、青色の65万円控除が無くても税金への影響は小さい
- 気をつけること: 働き方（決まった時間・場所で、会社の指示どおりに働く）が社員と同じだと、税務署や年金事務所から「給与（雇用）」とみなされることがある。その場合は源泉徴収と社会保険が必要になる。契約は「業務の範囲と報酬」で決め、やり方や時間は本人に任せる形を保つ

## 金額が変わる場合（坂本さんに確認中）

- 2026年1〜8月に、ほかの会社から給与をもらった人がいれば、その会社の源泉徴収票を合わせて年末調整する。この場合は税金が出ることがある
